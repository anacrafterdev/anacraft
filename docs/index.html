Slack alerts

      
Told, not asked.

      
A dashboard answers how is the site doing when somebody thinks to
      ask. craft watch answers the one nobody is awake to ask —
      did something break — and says it in Slack. A site's own history is
      the threshold, so there is nothing to configure for it to be useful.

      
     

     

    

    

      

        
# check once, print what moved, exit
$ craft watch

# pick a slack channel, then keep checking
$ craft slack --install
$ craft watch --every 3600

# see all three shapes on synthetic data
$ craft watch --demo

⛏ VILLAGERS      412  ▼38%
  28-day normal 664 · fires past 30%
⛏ DIAMONDS         0  nothing recorded
  28-day normal 12 · fires past 40%

      

      

        

          
Fires onWhich is

          
dropDown past the metric's threshold — 30% for users, 40% for conversions, 20% for bounce rate

          
spikeUp past the same line. A good morning is worth knowing about too

          
silentA count that went to nothing against a baseline that was not nothing — a deleted tag, a broken banner, a site that is down

          
no dataNothing anywhere in the window. Said once, rather than as six metrics all going quiet

        

        

          Tuned per property when the defaults are wrong for your site, and
          silent about a day it has already told you about — one message about a
          drop, not one an hour.

Quick start

    
Two minutes from curl to numbers.

    

      Official builds carry their own OAuth client, so craft login needs no
      Google Cloud project. No property yet? Create one from the dashboard,
      then connect it here. Everything on this page is free.
    

    

      

        
# install — gives you `craft`, and `anacraft` as an alias
$ curl -fsSL https://anacraft.dev/install.sh | bash

# no command = the dashboard; no property = synthetic data
$ craft

# connect your GA4 property
$ craft login
$ craft props
$ craft use 1234567

# one-shot reports
$ craft overview --days 30
$ craft pages
$ craft realms

Audit

    
Before you trust a number.

    

      craft audit checks whether your property is measuring the site
      correctly: sixteen checks over four weeks, each finding graded with what fixes it.
      --fix applies the ones Google Analytics can repair itself.
    

    

      

        
# sixteen checks over the last 28 days
$ craft audit

# ...and apply the ones GA4 can fix itself
$ craft audit --fix

# see the whole shape of a report, no account
$ craft audit --demo

█ KEY EVENTS NEVER FIRED
  purchase, generate_lead
  configured as an outcome and not recorded
  once in 28 days…
█ PURCHASES ARRIVE WITHOUT THEIR MONEY
  412 purchases · 0 revenue
▓ A PAYMENT PAGE IS CREDITED WITH CONVERSIONS
  checkout.stripe.com

  12 checks run · 2 critical · 1 warning

      

      

        

          
FindsWhich is

          
no key eventsTraffic arriving and nothing marked as the point — no report on the property can say whether any of it was worth having

          
never firedA key event configured and not recorded once. Names match exactly, so Purchase and purchase are two events and only one counts

          
no revenuePurchases arriving without their value — every revenue and ROAS figure reads zero, including in an Ads account importing from here

          
counted twiceA bounce rate near nothing with the page views doubled — the shape a second page_view tag makes

          
self-referralThe site or a payment page credited with its own conversions, because the return trip starts a fresh session

          
went quietAn event that fired last month and not this one — a tag removed, renamed, or moved behind something that no longer runs

        

        

          It reports the symptom and names the usual cause, never the other way
          round — and every check has a floor, so a quiet property gets
          not run rather than a list of things to dismiss. Exits
          2 when it finds something,
          so a weekly audit into Slack is one cron line.
          What the audit checks →
